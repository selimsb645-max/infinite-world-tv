# INFINITE WORLD TV — Asset Licensing

All assets in this project are **original works** created for
INFINITE WORLD TV. No external assets are used.

- **Characters** (Pip, Zara, Milo, Nova): original designs built
  from Godot primitives in `game/scripts/character_factory.gd`.
  No recognisable copyrighted character is imitated.
- **Vehicles** (SportsCar, OffRoad, Futuristic, Compact, Fantasy):
  original designs in `game/scripts/vehicle_factory.gd`. No real
  automotive logos or trademarked designs.
- **Environment props, obstacles, collectibles**: original
  primitive builds in `game/scripts/environment_assets.gd` and
  `game/scripts/obstacle_collectible_library.gd`.
- **Audio** (`game/assets/audio/*.wav`): original synthesis
  generated by `tools/generate_audio.py` (sine/triangle/noise
  envelopes). No external or licensed audio, no samples.
- **Materials / VFX**: procedural `StandardMaterial3D` and
  `GPUParticles3D` only; no external textures or shaders.

Third-party code: Godot Engine 4.3 (MIT licence) only, used as the
runtime. Nothing else is bundled.
